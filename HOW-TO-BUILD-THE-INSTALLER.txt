How to get Tapsquatch-Setup.exe (no tools needed on your PC)
============================================================

GitHub builds the installer for you on a Windows machine.

FIRST TIME
1. Go to github.com and sign in as madebysilverback.
   (Check Settings > Public profile: the "Name" there is what shows on
   your uploads - leave it as Made by Silverback, not your real name.)
2. Click "+" (top right) > New repository.
   Name: Tapsquatch.  Choose Private for now.  Click Create repository.
3. On the new page click "uploading an existing file".
4. Open the unzipped Tapsquatch folder, select EVERYTHING inside it
   (including the ".github" and "installer" folders) and drag it onto
   the GitHub page. Click "Commit changes".
5. Click the "Actions" tab > "Build Windows installer" (left) >
   "Run workflow" > green "Run workflow" button.
6. Wait about 3-5 minutes until the run shows a green tick. Click the run,
   scroll to "Artifacts", click "Tapsquatch-Setup". It downloads a zip
   with Tapsquatch-Setup.exe inside.

EACH UPDATE
Unzip my new files over your folder, upload the changed files to GitHub
the same way (it replaces the old ones), then repeat step 5-6.

RELEASING TO USERS (later)
Make the repository public, then on GitHub: Releases > Draft a new
release > tag "v0.1.0" > Publish. The installer is built and attached
to the release automatically for people to download.

NOTE: Windows may say "Windows protected your PC" because the installer
isn't digitally signed yet. Click "More info" > "Run anyway". A code
signing certificate removes this warning - worth doing before a public
launch.
